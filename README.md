# Klinika Vita — ClinicAppointments

Sistem për rezervimin e termineve në klinikë: pacientë, mjekë dhe administrator.

## Si ta nisësh lokal

```bash
npm install
npm run dev
```

Hape në [http://localhost:3000](http://localhost:3000).

## Llogari demo

- Pacient: `pacient@klinikavita.com` / `pacient123`
- Mjek: `erta.berisha@klinikavita.com` / `mjek123`
- Admin: `admin@klinikavita.com` / `admin123`

Lokal, të dhënat ruhen në `data/db.json`. Në Vercel përdoret një bazë në memorie (për demo).
